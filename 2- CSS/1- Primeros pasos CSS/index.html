Introducción a CSS

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Es el lenguaje que se usa para darle estilo y presentación visual a los documentos HTML, es decir, controla colores, tamaños, espaciados y la disposición de los elementos en la pantalla. Se llama "en cascada" porque los estilos se van aplicando y combinando siguiendo un order de prioridad. CSS permite separar el contenido (HTML) de la presentación (estilos), lo que hace que el código sea más ordenado y fácil de mantener. Este documento está linkeado con el archivo styles.css.

Diferencia entre display: none y visibility: hidden

La diferencia es que display: none quita completamente el elemento del flujo del documento (como si no existiera: no ocupa espacio y no se puede interactuar con él), mientras que visibility: hidden lo oculta visualmente pero sigue ocupando su espacio en la página (el hueco queda ahí, aunque no se vea el contenido).
